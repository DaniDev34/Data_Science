# Actividad 2

## Introducción

En esta actividad se desarrolla un análisis exploratorio de datos enfocado en el estudio del comportamiento de ventas de una tienda en línea. A través del uso de herramientas como Python y MongoDB, se busca comprender cómo se generan, almacenan y analizan los datos, con el objetivo de obtener información relevante que apoye la toma de decisiones dentro de una organización.

El análisis de datos es una parte fundamental en el contexto actual, ya que permite identificar patrones, tendencias y oportunidades de mejora en los procesos de negocio. En este caso, se trabajará con datos simulados que representan ventas, clientes y productos, los cuales serán procesados y analizados para responder preguntas clave relacionadas con el rendimiento comercial.

Durante el desarrollo de la actividad, se aplicarán conceptos de ciencia de datos, bases de datos NoSQL y análisis estadístico, integrando distintas tecnologías para construir un flujo completo de trabajo, desde la generación de datos hasta su visualización e interpretación.

---

## Evaluables de la actividad:

El desarrollo de esta actividad será evaluado en función de los siguientes aspectos:

### 1. Definición del problema
Se espera que el objetivo del análisis esté claramente definido, junto con las preguntas de investigación que guiarán el estudio de los datos.

### 2. Generación de datos
Se evaluará la correcta creación de un conjunto de datos que cumpla con los requisitos establecidos, incluyendo variedad de tipos de datos y una cantidad suficiente de registros para el análisis.

### 3. Uso de MongoDB
Se verificará la correcta carga y manejo de los datos en una base de datos NoSQL, así como su consulta para el análisis posterior.

### 4. Análisis exploratorio de datos
Se evaluará el uso adecuado de herramientas como Pandas y NumPy para obtener estadísticas descriptivas, identificar patrones y manipular los datos.

### 5. Visualización de datos
Se considerará la correcta implementación de gráficas (boxplot, scatter plot e histograma) que permitan representar la información de manera clara y comprensible.

### 6. Interpretación de resultados
Uno de los puntos más importantes es la capacidad de interpretar los resultados obtenidos, explicando qué significan los datos y cómo pueden apoyar la toma de decisiones.

### 7. Organización y documentación
Se evaluará la claridad del código, la estructura del proyecto y la correcta documentación dentro del repositorio de GitHub.

## Enfoque de la actividad

El desarrollo de esta actividad sigue un flujo de trabajo basado en ciencia de datos:

1. Definición del problema
2. Generación y recopilación de datos
3. Almacenamiento en MongoDB
4. Análisis exploratorio con Python
5. Visualización de datos
6. Interpretación de resultados

Este enfoque permite simular un entorno real de trabajo, donde los datos se convierten en una herramienta clave para la toma de decisiones estratégicas.
